# E15 pre-registration: do big-spread games go OVER the opening total? (forward test)

Written 2026-10-23, after E14 and **before any E15 number exists**. Nothing is computed by this document. Criteria are not edited
after the first forward game is scored; a badly specified criterion is reported as a limitation, not changed.

## Why the old data cannot confirm this

E14 found a positive slope of `r = actual total - opening total` on `|opening spread|` (+0.18 points per spread point, interval
+0.08 to +0.28, 8,897 games, 2019-20 to 2025-26). That sign was **suggested by** those games (it is the mirror of a registered hypothesis that failed), so they cannot also confirm it:
a result chosen after looking is biased upward, which is why the power table below also uses a shrunk slope. Evidence from 2019-20..2025-26 is descriptive only in E15 and carries no
weight in any criterion below. The seasons before 2019-20 are a different odds source (archive file), were already looked at in E14 (slope
-0.05, interval -0.16 to +0.06), and are not used either.

The only untouched data is the future. E15 is a forward test.

## Definitions (identical to E14 so the two can be compared)

- `odds_total`, `odds_home_spread`, `target_total_pts`: from the training set generated by `scripts/generate_training_set.py`, same priority-book opening
  line as E14. `|spread|` = absolute opening home spread. `r = target_total_pts - odds_total`. Push = `r == 0`.
- Same plausibility filter as E14 (total in 170..290, |spread| <= 30). Same overtime flag (either team's `minutes` > 240 in `team_game_full`).
- **Forward sample F**: regular-season games with `gameDate >= 2026-10-24` and a non-missing opening total, spread and result. The 16 games already
  played in 2026-27 (through 2026-10-22) are excluded so the sample starts after this document. No other game is dropped except by the
  plausibility filter. Games enter F as the training set is regenerated; nothing is selected by outcome.
- Intervals: day-cluster bootstrap, 1000 draws, seed 20261017 (`experiments/metrics.py`), as in E14.

## Hypothesis H2 (sign fixed now)

The slope of `r` on `|spread|` in F, OLS with intercept and no controls, is **positive**.

**H2 is SUPPORTED iff, at the single decisive evaluation, the lower end of the one-sided 95% bound (the 5th percentile of the bootstrap slope
draws) is above 0.** This is the sign-fixed analogue of E14's rule. The two-sided 95% interval is reported next to it but does not decide.
If the bound is not above 0, H2 is NOT SUPPORTED, including when the point estimate is positive.

## Sample size and looks (fixed now, so there is no stopping on a lucky run)

- Decisive evaluation: once, when F reaches **3,900 games** (about three regular seasons, i.e. mid-to-late spring 2029). It uses all games then in F.
- Non-decisional looks at 1,300 and 2,600 games: report the same statistics, change no criterion, stop nothing, bet nothing on them.
- Power at the decisive size (slope SE 0.075, scaled from E14's 0.050 at n = 8,897; one-sided 5%):

| true slope | n = 1,300 | n = 2,600 | n = 3,900 | n = 5,300 |
|---:|---:|---:|---:|---:|
| 0.18 (E14 point estimate) | 40% | 62% | 77% | 87% |
| 0.12 (a shrunk value, since E14 chose this sign by looking) | 23% | 37% | 48% | 58% |
| 0.09 (about E14's lower bound) | 17% | 25% | 33% | 40% |

  So even a real effect of the E14 size fails to show about one time in four, and a smaller real effect fails to show about half the time or more.
  A NOT SUPPORTED result will therefore mean "not shown at this sample size", not "absent".

## Secondary readings (descriptive; none changes the verdict)

1. Under and over rates by bucket 0-3, 3-6, 6-9, 9-12, 12+, pushes excluded, same table as E14 step 2.
2. The slope with `odds_total` and season added; the slope on regulation-only games; the slope of `actual - closing total`.
3. The deployed model's residual slope: slope of `actual - total_pred` on `|spread|` for the same games (predictions as produced live, never refit
   for this purpose).
4. Season-by-season slopes of F, to show whether a result depends on one season.

## Betting readout (reported, not a decision rule for stakes)

Flat over bet at -110 when `|spread| >= 10`, at the opening total and at the best-book line and quoted price (E12 method), return per bet with day-bootstrap
interval. The threshold 10 is fixed now and is **not** the data-chosen 12 from E14's exploratory run. Break-even is a 52.38% over rate.
At 3,900 games about 620 bets fall in this bucket (16% of games, as in E14), so the return interval will be about ±8 percentage points (E14's 529 confirmation bets gave ±8.5): it can
show a gross failure, it cannot confirm an edge smaller than that. No bet-sizing conclusion follows from E15 unless H2 is SUPPORTED **and** the best-book return point estimate is positive; even then the interval is
reported and is the evidence, not the point estimate.

## If H2 is supported: feature step

Only then run the standard feature experiment (`experiments/feature_exp.py`) adding `abs_spread` (and separately `env_blowout_prob` from
`props/features/market_env.py`) against the baseline and the noise floor, under `PREREGISTRATION.md`'s common protocol (seven walk-forward folds plus the
forward seasons as extra test folds; main criterion MC requires the forward folds not to be worse). No feature is built before then.

## Choices made here that you can change before the first scoring

1. Decisive size 3,900 games (three seasons). Smaller means faster and weaker; 5,300 gets about 87% power for the E14 size but takes four seasons.
2. One-sided 5% instead of E14's two-sided 95%, because the sign is fixed in advance. Two-sided would cut power at 3,900 games from 77% to 67% for a 0.18 slope.
3. Over threshold 10 for the betting readout.
4. Forward start 2026-10-24.

## Out of scope

No claim about spread, moneyline or player-prop markets; no use of any 2013-14..2025-26 game as evidence; no tuning of any threshold on F.
